# claude-geo — Generative Engine Optimization for Claude Code

A modular Claude Code skill for auditing and improving how AI engines
(ChatGPT, Claude, Perplexity, Google AI Overviews + AI Mode, Gemini 3,
Copilot) cite and recommend a brand or product.

Designed to **coexist with [claude-seo](https://github.com/AgriciDaniel/claude-seo)** —
different command namespace (`/geo` vs `/seo`), no overlap, no overrides.

## Quick start

```bash
# See what the plugin can do
/geo help

# Run a full GEO audit (produces MD + HTML deck + HTML guide)
/geo audit https://example.com

# Audit a single pillar
/geo technical https://example.com
/geo content https://example.com
/geo schema https://example.com
/geo presence "Example Brand"
/geo mentions "Example Brand"

# Verify a specific technique was applied
/geo verify schema-knowsabout https://example.com
/geo verify robots-txt https://example.com
/geo verify content-bluf https://example.com

# Build a 90-day plan
/geo plan https://example.com

# Generate reports from an existing audit
/geo report all https://example.com
```

## What's included

### 12 sub-skills

| Skill | Purpose |
|-------|---------|
| `geo` | Orchestrator. Routes commands to sub-skills. |
| `geo-audit` | Full audit. Spawns all sub-agents in parallel. |
| `geo-technical` | robots.txt for AI bots, llms.txt, SSR vs JS-only, sitemap, Cloudflare. |
| `geo-content` | CITABLE framework scoring, passage analysis, tables/lists/sentence-length. |
| `geo-schema` | JSON-LD with `knowsAbout`, `sameAs`, FAQPage (AI extraction), entity chain. |
| `geo-presence` | Off-site presence interview + automated verification. |
| `geo-mentions` | Real LLM mention checks across ChatGPT/Claude/Perplexity/Google AIO. |
| `geo-reddit` | Reddit presence audit + 6-step organic playbook. |
| `geo-trust` | Wikipedia, Wikidata, G2/Capterra/Trustpilot — including the **G2 4.0 rule**. |
| `geo-plan` | Sequenced 90-day roadmap combining technical + creative actions. |
| `geo-verify` | Verifier dispatcher. Run real checks after implementing changes. |
| `geo-report` | Report generator: MD + HTML technical guide. |

### 7 sub-agents

`geo-technical`, `geo-content`, `geo-schema`, `geo-presence`, `geo-mentions`,
`geo-reddit`, `geo-reporter`.

### 12 scripts (9 real-check verifiers + scoring + report + page fetcher)

| Script | What it checks |
|--------|---------------|
| `fetch_page.py` | Page fetch + SSR vs JS-only detection. |
| `check_robots_txt.py` | AI crawler access (OpenAI three-bot, Anthropic three-bot framework, Perplexity, Google-Extended). |
| `check_llms_txt.py` | llms.txt presence and structural validation. |
| `check_schema.py` | JSON-LD extraction, Organization.knowsAbout/sameAs, FAQPage, entity chain. |
| `check_content_structure.py` | Tables, lists, sentence length, passage segmentation, front-loading, date visibility. |
| `check_wikipedia.py` | Wikipedia + Wikidata presence via official APIs (no key required). |
| `check_trust_sites.py` | G2, Capterra, Trustpilot, Software Advice, GetApp, TrustRadius listings. |
| `check_reddit_presence.py` | Reddit mentions in target subreddits with sentiment classification. |
| `check_youtube_presence.py` | YouTube videos mentioning brand (own vs third-party). |
| `check_llm_mentions.py` | Real LLM API queries (OpenAI / Anthropic / Perplexity) with WebSearch fallback. |
| `score_geo.py` | Aggregate weighted score + grade + top-5 action ranking. |
| `generate_report.py` | Render templates into MD + HTML guide. |

### 2 report formats

Generated by `/geo report all <url>`:

1. **`GEO-Audit-{slug}-{date}.md`** — Markdown audit document.
2. **`GEO-Guide-{slug}-{date}.html`** — Sidebar-navigated technical guide with per-pillar deep dives, Chart.js bar chart, dark theme. Suitable for sharing with leadership directly.

## Installation

`claude-geo` is a **Claude Code plugin** (not a standalone skill). It bundles
12 sub-skills, 7 sub-agents, and 12 Python scripts together. Once installed,
Claude Code auto-discovers all of it.

### Option A — `/plugin install` (Claude Code 1.0.33+)

```bash
# In Claude Code, register this repo as a marketplace (one-time)
/plugin marketplace add vladkomudrich/claude-geo

# Then install
/plugin install claude-geo@digital-vlad
```

### Option B — Manual `git clone` (any OS)

```bash
git clone https://github.com/vladkomudrich/claude-geo.git ~/.claude/plugins/claude-geo
```

To update later:

```bash
cd ~/.claude/plugins/claude-geo && git pull
```

### Option C — Copy from local

If you already have the source folder (e.g. cloned into a project):

```bash
cp -r claude-geo ~/.claude/plugins/
```

After any of the three options, restart Claude Code (or run `/plugin list` to
verify discovery). Then try `/geo help` to confirm.

### Verifying compatibility with claude-seo

```bash
# Both skills work side-by-side
/seo audit https://example.com    # claude-seo
/geo audit https://example.com    # claude-geo

# Different command namespaces — no collision
```

## Scoring model

A GEO Score is the weighted average of five pillars:

| Pillar | Weight | Verified by |
|--------|--------|-------------|
| Technical accessibility | 20% | `check_robots_txt.py`, `check_llms_txt.py`, `fetch_page.py --check-ssr` |
| Content citability | 25% | `check_content_structure.py` |
| Schema & entities | 15% | `check_schema.py` |
| Off-site presence | 25% | `check_wikipedia.py`, `check_trust_sites.py`, `check_reddit_presence.py`, `check_youtube_presence.py` |
| Real-world citations | 15% | `check_llm_mentions.py` |

Grades: A (85+), B (70-84), C (55-69), D (40-54), F (<40).

Full rubric in `skills/geo/references/scoring-rubric.md`.

## Key hard rules

1. **HowTo schema** — never recommend (rich results retired Sept 2023).
2. **`anthropic-ai` / `claude-web`** — never recommend in robots.txt (retired July 2024).
3. **G2 / Capterra / Trustpilot aggregate <4.0** — flagged as Critical (hard ChatGPT filter in competitive queries).
4. **JavaScript-only sites** — flagged as Critical (AI crawlers do not execute JS).
5. **FAQPage schema** — recommend with explicit caveat (Google rich results deprecated 7 May 2026; ChatGPT/Perplexity/Gemini still extract).
6. **llms.txt** — recommend for developer products (IDE agents consume it); low priority for non-developer products (Google publicly doesn't use it).

## API keys (optional, for direct LLM mention checks)

The `check_llm_mentions.py` script uses these environment variables if set:

- `OPENAI_API_KEY` — direct ChatGPT (web-search-enabled).
- `ANTHROPIC_API_KEY` — direct Claude.
- `PERPLEXITY_API_KEY` — direct Perplexity.

Missing keys → falls back to WebSearch with engine-specific filters, marked
as INDIRECT.

## Compatibility with claude-seo

| Aspect | claude-seo | claude-geo |
|--------|------------|------------|
| Command prefix | `/seo` | `/geo` |
| Skill folder prefix | `seo-*` | `geo-*` |
| Agent prefix | `seo-*` | `geo-*` |
| Output naming | `SEO-*` | `GEO-*` |

No filename, skill name, or agent name collision. Both can be installed
simultaneously and used in the same workflow:

```
/seo audit https://example.com    # core SEO foundations
/seo geo https://example.com      # quick GEO pass within SEO context
/geo audit https://example.com    # deep GEO audit with real verification
/geo plan https://example.com     # strategic 90-day roadmap
```

See `skills/geo/references/compatibility-with-seo.md` for the explicit
ownership map.
